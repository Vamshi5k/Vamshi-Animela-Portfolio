# VAMSHI.DEV

Personal portfolio of Vamshi Animela, React Native developer, Hyderabad, India.

Built with Next.js (App Router), TypeScript, Tailwind CSS, GSAP and Motion.

## Scripts

```bash
npm run dev        # start the dev server
npm run typecheck  # next typegen && tsc --noEmit
npm run lint       # eslint
npm run build      # production build
```

Project conventions and rules live in [CLAUDE.md](CLAUDE.md).
